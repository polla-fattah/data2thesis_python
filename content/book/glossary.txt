# Glossary of key terms for Appendix B.
# One entry per line:  Term | alias | alias :: Definition
# The chapters are added automatically from each chapter's "Key terms" list,
# matching the term and its aliases (ignoring case). Rendering Appendix B stops
# with an error if a chapter's key term has no entry here.

accuracy :: The share of cases a classification model classifies correctly. Misleading when one outcome is rare.
activation function :: The function a neuron applies to its weighted total to produce its output, such as the sigmoid or the ReLU.
adjusted R-squared :: R-squared corrected for the number of predictors, so that adding useless predictors does not make a model look better.
adjusted Rand index :: A measure of agreement between two clusterings or classifications, corrected for chance: 1 means identical groupings, 0 means chance agreement.
AI coding assistant :: An AI tool that writes, explains, or completes code, in a chat or inside the editor. Its suggestions must be checked.
AIC :: Akaike information criterion: a measure for comparing models that balances fit against complexity; lower is better.
alternative hypothesis :: The claim that there is an effect or a difference, tested against the null hypothesis.
annotation :: Text, arrows, or shapes added to a plot to point out something specific.
anonymisation :: Removing or altering information so that the people in a dataset cannot be identified.
ANOVA :: Analysis of variance: a test of whether the means of three or more groups differ, by comparing variation between groups with variation within them.
API :: Application programming interface: a way for one program to send requests to another, such as Python sending text to a language model.
API key :: A secret code that identifies you to an online service's API. Keep it in an environment variable or `.env` file, never hardcoded in a script.
argument :: A value passed to a function inside its parentheses, such as `dropna=True`, that controls what the function does.
ARIMA :: A family of time series models that forecast from the autocorrelation of the series and past random shocks.
artificial intelligence :: Computer systems that perform tasks usually needing human intelligence, such as understanding language; in this book, mainly large language models.
assignment :: Storing a value in a variable with `=`, as in `x = 5`.
attrition :: The loss of participants from a study over time.
autocorrelation :: The correlation between a time series and itself a number of steps (lags) earlier.
bar chart :: A plot of counts or values as bars, one per category.
baseline model :: The simplest possible model, such as predicting the mean for everyone, used as a benchmark for real models.
Bayesian information criterion (BIC) | BIC :: A criterion for comparing models that rewards fit and penalises complexity. In scikit-learn Gaussian mixture models, lower BIC indicates a better model.
benchmark forecast :: A simple forecast, such as the mean or the value a season earlier, that any serious method should beat.
between-group variation :: How much group means differ from the overall mean; the numerator of the ANOVA F statistic.
bias :: In a neural network, the constant added to a neuron's weighted total (like an intercept). More generally, a systematic error.
BibTeX :: A text format for bibliographic references, used by Quarto to format citations and reference lists.
bimodal :: Having two peaks.
bin :: One of the intervals into which a histogram divides the values.
boosting :: Building a model by adding many small models (usually trees) one at a time, each correcting the errors of the model so far.
bootstrap :: Estimating uncertainty by repeatedly resampling the data with replacement and recalculating a statistic.
bootstrap sample :: A sample of the same size as the data, drawn from it at random with replacement.
border point :: In DBSCAN, a case near a core point that belongs to its cluster but is not itself a core point.
box plot :: A plot that shows the median, the quartiles, and unusual values of a variable.
summary table :: A tidy table that summarizes model results (coefficients, standard errors, p-values), constructed with pandas from statsmodels or scikit-learn outputs.
central limit theorem :: The result that the sampling distribution of a mean is approximately normal for large enough samples, whatever the shape of the data.
centring :: Subtracting the mean from a variable, so that zero means "average"; often used before fitting interactions.
chi-square test :: A test for categorical data: whether counts fit expected proportions (goodness of fit), or whether two categorical variables are related (independence).
chunk option :: A setting for a code chunk in a Quarto document, written as `#| option: value`, such as `echo: false`.
citation :: A reference to a source in the text, written in Quarto as `[@key]`.
citation style (CSL) :: A file in the Citation Style Language that sets how citations and references are formatted, such as APA.
class weights :: Making errors on a rare class count more when a model is fitted, one remedy for imbalanced outcomes.
classification :: Predicting a category, such as whether a student will consider dropping out.
cluster analysis :: Methods that group cases so that cases in the same group are similar to each other.
code chunk :: A block of code in a Quarto document that is run when the document is rendered.
codebook :: A description of every variable in a dataset or, in qualitative coding, of every theme and how to assign it.
coefficient path :: A plot of how each coefficient of a regularised model changes as the penalty changes.
Cohen's *d* :: An effect size for the difference between two means, in standard deviations.
Cohen's kappa :: A measure of agreement between two coders or classifiers, corrected for the agreement expected by chance.
comment :: Text in a script after `#`, which Python ignores; used to explain the code.
commit :: In git, a saved snapshot of a project, with a message describing the change.
confidence interval :: A range of plausible values for a population quantity, calculated from a sample, with a stated level of confidence such as 95%.
confirmatory analysis :: An analysis planned before seeing the data, to test a specific hypothesis.
confirmatory factor analysis :: Factor analysis that tests a factor structure specified in advance.
confounder :: A variable related to both the predictor and the outcome, which can create or hide an apparent effect.
confusion matrix :: A table of predicted against actual classes, showing true and false positives and negatives.
terminal | interactive window :: The editor pane or interactive REPL where Python commands are run and results appear.
convolutional network :: A type of deep neural network designed for images.
core point :: In DBSCAN, a case with at least `minPts` cases within distance `eps`.
correlation coefficient :: A number from −1 to 1 measuring the strength and direction of a straight-line relationship between two variables.
correlation matrix :: A table of the correlations between every pair of variables.
count outcome :: An outcome that counts events (0, 1, 2, ...), usually modelled with a Poisson model.
covariance matrix :: A table of the variances and covariances of several variables; in a mixture model it sets the shape of a cluster.
Cronbach's alpha :: A measure of the internal consistency (reliability) of a scale made of several items.
cross-loading :: An item that loads substantially on more than one factor.
cross-reference :: A reference in a Quarto document, such as `@fig-wellbeing`, that becomes a numbered link.
cross-validation :: Estimating how well a model predicts new data by repeatedly fitting it on part of the training data and testing it on the rest.
CSV file :: A plain-text file of comma-separated values, the most common format for sharing data tables.
data frame | DataFrame :: A two-dimensional tabular data structure in pandas: columns are variables, rows are cases.
data leakage :: Information from the test data reaching the model during training, which makes its performance look better than it is.
data structure :: The way data is organised in Python: list, dictionary, tuple, NumPy array, or pandas DataFrame.
data type :: The kind of value: numeric, integer, character, or logical.
DBSCAN :: A clustering method that finds dense regions of cases and labels cases in sparse regions as noise.
decision tree :: A model that predicts by a series of yes-or-no questions about the predictors.
decomposition :: Splitting a time series into trend, seasonal, and remainder components.
deep learning :: Neural networks with many hidden layers, used for images, sound, and text.
dendrogram :: The tree diagram produced by hierarchical clustering.
density :: In clustering, how closely packed cases are in a region.
density plot :: A smooth version of a histogram, showing the shape of a distribution.
descriptive statistics :: Numbers that summarise data, such as means, medians, and standard deviations.
diagnostic plot :: A plot used to check a model's assumptions, such as residuals against fitted values.
dictionary method :: Classifying texts by counting keywords from a list for each category.
diminishing returns :: A relationship that levels off, so each extra unit of the predictor adds less than the one before.
disclosure :: Stating in a publication how AI tools or other aids were used.
distance :: How different two cases are, calculated from their values on several variables.
DOI :: Digital object identifier: a permanent identifier for a publication or dataset, such as `10.1126/science.1213847`.
downsampling :: Balancing classes by randomly removing cases of the common class from the training data.
dpi :: Dots per inch: the resolution of a saved image; 300 dpi is usual for print.
dummy variable :: A 0/1 variable representing one category of a categorical predictor.
effect size :: A measure of how large an effect is, independent of sample size, such as Cohen's *d* or eta squared.
eigenvalue :: In PCA, the amount of variance captured by a component.
elastic net :: Regularised regression that mixes the ridge and lasso penalties.
elbow method :: Choosing the number of clusters where adding more stops reducing within-cluster distance much.
ensemble :: A model that combines the predictions of many models, such as a random forest.
epoch :: One pass through the training data when training a neural network.
eps :: In DBSCAN, the radius of the neighbourhood around each case.
error message | exception :: Python's message when something goes wrong, providing an informative traceback of what occurred and where.
eta squared :: An effect size for ANOVA: the share of the variation in the outcome explained by the groups.
expected count :: In a chi-square test, the count expected in a cell if the null hypothesis were true.
explanation :: Using a model to understand why something happens, rather than to predict new cases.
exploratory analysis :: Exploring data to find patterns and generate questions, rather than to test planned hypotheses.
exponential smoothing (ETS) | ETS :: Forecasting with weighted averages of past observations, with more weight on recent ones; ETS models the error, trend, and season.
external validation :: Checking clusters or predictions against known categories or outcomes.
F statistic :: In ANOVA, the ratio of between-group to within-group variation.
F1 score :: A single measure combining precision and recall (their harmonic mean).
facet :: A small panel of a plot showing one subgroup; `facet_wrap()` makes one panel per group.
factor :: In pandas, a categorical series (`Categorical`) with a fixed set of categories. In factor analysis, a hidden (latent) variable underlying observed items.
factor analysis :: A method that explains the correlations among items by a smaller number of hidden factors.
false negative :: A case that belongs to the positive class but is predicted negative.
false positive :: A case predicted positive that belongs to the negative class.
fixed effect :: In a mixed model, an effect assumed the same for everyone, such as the average change over time.
fold :: One of the parts into which the data is split for cross-validation.
forecast horizon :: How far ahead a forecast is made.
Fourier terms :: Pairs of sine and cosine waves used as predictors to describe a seasonal pattern.
function :: A named piece of code that takes arguments and returns a result, such as `mean()`.
Gaussian mixture model :: A model that describes data as a mix of normal distributions, giving each case a probability of belonging to each cluster.
generalised linear mixed model :: A mixed-effects model for outcomes that are not normal, such as counts or yes/no outcomes.
plot kind :: The geometric visualization representing data in matplotlib/seaborn, such as scatter points, lines, bars, or boxes.
Gini impurity :: A measure of how mixed the classes are in a group; decision trees choose splits that reduce it.
git :: The standard version control system, which records the history of a project.
GitHub :: A website for storing git projects online, sharing them, and working on them together.
gradient :: The direction and rate at which the error changes as each weight changes.
gradient descent :: Training a model by repeatedly moving the weights a small step in the direction that reduces the error.
grammar of graphics :: The conceptual foundation of statistical plotting: visual representations are built systematically from data, aesthetic mappings, and visual geometries.
grouped summary :: Summary statistics calculated separately for each group, for example with `summarise(.by = ...)`.
hallucination :: Plausible but invented content produced by a language model, such as a function or reference that does not exist.
heat map :: A grid of coloured cells showing values, such as a correlation matrix.
helper function :: A small function written to avoid repeating the same code, such as one that formats means.
hidden layer :: A layer of neurons between the inputs and the output of a neural network.
hierarchical clustering :: Clustering that repeatedly merges the most similar groups, producing a dendrogram.
histogram :: A plot of the distribution of a numeric variable, as bars counting the values in each bin.
hyperparameter :: A setting of a model that is chosen before fitting rather than learned from the data, such as the number of neighbours in k-NN.
identifier :: A variable that uniquely identifies each case, such as `student_id`.
imbalanced outcome :: An outcome in which one class is much rarer than the other.
imputation :: Filling in missing values with estimated ones, such as the median.
independence :: The assumption that observations do not influence each other; in a chi-square test, the hypothesis that two variables are unrelated.
index :: In a tsibble, the column that holds time.
inferential analysis :: Using a sample to draw conclusions about a population.
inline code :: Code (such as Python expressions) inside a sentence of a Quarto document, evaluated and replaced by its result when rendered.
input :: In Shiny, a control such as a menu or slider whose value the user chooses.
input layer :: The inputs (predictors) of a neural network.
interaction :: When the effect of one predictor depends on the value of another.
interaction plot :: A plot of group means that shows whether the effect of one factor depends on another.
intercept :: The predicted value of the outcome when all predictors are zero.
internal validation :: Judging clusters by how compact and separated they are, using the data alone, as with the silhouette.
interquartile range :: The range of the middle 50% of the values: the third quartile minus the first.
intraclass correlation :: The share of the total variation that lies between groups (such as students or supervisors).
join :: Combining two tables by matching rows on a key, such as `student_id`.
k-means :: A clustering method that assigns each case to the nearest of *k* cluster centres and moves the centres to the means.
k-nearest neighbours :: Predicting a case from the *k* most similar cases in the training data.
k-nearest-neighbour distance plot :: A sorted plot of each case's distance to its *k*-th nearest neighbour, used to choose `eps` for DBSCAN.
Kaiser rule :: Keeping components with an eigenvalue above 1; a rough guide that often keeps too many.
kernel :: In a support vector machine, a function that allows curved boundaries between classes.
Jupyter kernel :: The execution engine that runs Python code chunks inside Quarto and Jupyter documents.
Kruskal-Wallis test :: A non-parametric alternative to one-way ANOVA.
lag :: The number of time steps between an observation and an earlier one it is compared with.
large language model :: A neural network trained on huge amounts of text to predict the next token, used in AI assistants.
lasso :: Regularised regression with a penalty on the absolute size of the coefficients, which sets some of them to exactly zero.
LaTeX :: A typesetting system whose notation is used to write equations, as in `$\bar{x}$`.
layer :: In data visualization, an overlaid graphical element on an axis. In a neural network, a group of neurons that transforms input data.
leaf :: A final node of a decision tree, which gives the prediction.
learning rate :: In boosting and neural networks, how large a step each update takes.
least squares :: Choosing a regression line that minimises the sum of the squared residuals.
level :: One of the categories of a factor.
Levene's test :: A test of whether groups have equal variances.
licence :: A statement of what others may do with shared data or code, such as CC BY or MIT.
likelihood ratio test :: A test comparing two nested models by how much better the larger one fits.
line chart :: A plot of values connected by lines, often over time.
linear regression :: A model of a numeric outcome as a straight-line function of one or more predictors.
list :: A standard Python data structure that holds an ordered sequence of items of any type, written with square brackets `[...]`.
loading :: The correlation between an item and a factor or component.
local model :: A language model that runs on your own computer, so data does not leave it.
lockfile :: A file, such as renv's `renv.lock`, that records the exact package versions of a project.
log-odds :: The logarithm of the odds; the scale on which logistic regression coefficients are estimated.
logical indexing :: Selecting elements with a TRUE/FALSE condition, as in `x[x > 5]`.
logistic regression :: A regression model for a yes/no outcome, which predicts the probability of "yes".
long format :: Data with one row per observation, such as one row per student per semester.
machine learning :: Methods that learn patterns from data to make predictions or find structure, judged by performance on new data.
MAE :: Mean absolute error: the average size of the prediction errors.
main effect :: The effect of one factor, averaged over the levels of another.
Mann-Whitney U test :: A non-parametric test comparing two independent groups.
mapping | visual mapping :: Linking a dataset column to a visual property, such as x/y position, hue, style, or size.
margin :: In a support vector machine, the empty band between the classes and the boundary.
Markdown :: A simple way of formatting text with symbols, such as `**bold**` and `# Heading`.
matrix :: A two-dimensional table of values of one type.
mean :: The average: the sum of the values divided by their number.
mean method :: A benchmark forecast that predicts the average of past observations.
median :: The middle value when the values are sorted.
membership probability | soft assignment :: The probability that a case belongs to each cluster, as given by a mixture model.
method choice :: Choosing an analysis method from the goal, the type of outcome, and how observations are related.
minPts :: In DBSCAN, the number of cases a neighbourhood must contain for a case to be a core point.
missing at random :: Missingness that depends only on observed variables, not on the missing values themselves.
missing code :: A value such as `99` or `-9` used in raw data to mark a missing answer.
missing completely at random :: Missingness unrelated to any variable, observed or not.
missing not at random :: Missingness that depends on the missing values themselves.
missing value (`NA` / `NaN`) | NA | NaN :: A marker for a missing or unrecorded value, represented in Python by `None`, `np.nan`, or `pd.NA`.
mixed-effects model :: A regression model with both fixed effects and random effects, for repeated or nested data.
mixing probability :: In a mixture model, the share of cases belonging to a component.
mixture :: In regularised regression, the mix of lasso and ridge penalties, from 0 (ridge) to 1 (lasso).
mixture component :: One of the normal distributions in a Gaussian mixture model.
mode :: The most common value.
model specification :: Initializing an estimator with chosen hyperparameters in scikit-learn or specifying a formula in statsmodels before fitting.
`mtry` | mtry :: In a random forest, the number of predictors each split may choose from.
multicollinearity :: Strong correlation among predictors, which makes regression coefficients unstable.
multilayer perceptron :: A neural network with one or more hidden layers of neurons.
multilevel model :: Another name for a mixed-effects model, emphasising nested levels.
multiple regression :: Linear regression with more than one predictor.
multivariate analysis :: Methods that analyse many variables at once, such as PCA and factor analysis.
naive method :: A benchmark forecast that repeats the last observed value.
nested data :: Data in which cases are grouped within units, such as students within supervisors.
neural network :: A model made of connected neurons in layers, whose weights are learned from data.
neuron (unit) | neuron | unit :: The basic element of a neural network: it weights its inputs, adds a bias, and applies an activation function.
node :: A point in a decision tree where a question is asked or a prediction is made.
noise :: In DBSCAN, cases in sparse regions that belong to no cluster.
non-parametric test :: A test that does not assume a particular distribution, often based on ranks.
normal distribution :: The symmetric, bell-shaped distribution described by a mean and a standard deviation.
normalisation :: Rescaling variables, usually to z-scores, so that they are on the same scale.
null hypothesis :: The claim of no effect or no difference, which a test tries to reject.
object :: An entity in Python (such as a number, string, list, or DataFrame) that has a data type, identity, and methods.
oblique rotation :: A factor rotation that allows the factors to correlate.
odds :: The probability of an event divided by the probability of it not happening.
odds ratio :: The ratio of the odds in two groups; in logistic regression, the multiplicative change in odds per unit of a predictor.
one-sample t-test :: A test of whether a mean differs from a given value.
one-tailed test :: A test that looks for a difference in one direction only.
open science :: Practices that make research transparent and reusable: sharing data and code, preregistration, and open access.
outcome :: The variable a model explains or predicts.
outlier :: A value far from the others.
output :: In Shiny, a plot, table, or text that the server produces for the user interface.
output format :: The kind of document Quarto produces, such as HTML, Word, or PDF.
output layer :: The final layer of a neural network, which produces the prediction.
overfitting :: A model learning the noise in its training data, so it performs well there and poorly on new data.
overplotting :: Points drawn on top of each other in a plot, hiding how many there are.
p-value :: The probability of results at least as extreme as those observed, if the null hypothesis were true.
package | library :: A collection of Python modules, functions, and classes (such as pandas or seaborn) installed via `pip`.
paired t-test :: A test comparing two measurements on the same cases.
Pandoc :: The document converter that Quarto uses to produce HTML, Word, PDF, and other formats.
parallel analysis :: Choosing the number of factors by comparing eigenvalues with those from random data.
parameter :: A quantity describing a population (Chapter 7); a value learned by a model, such as a coefficient (Chapter 11); or an input to a Quarto report (Chapter 17).
subplots :: Matplotlib's system (`plt.subplots()`) for combining multiple plot axes into a single coordinated figure.
penalty (lambda) | penalty | lambda :: In regularised regression or a neural network, the strength of the penalty on large coefficients or weights.
permutation importance :: A predictor's importance measured by how much shuffling its values reduces a model's accuracy.
pipe :: The operator `|>`, which passes the result on its left to the function on its right.
pipeline :: The series of steps, in code, from raw data to results.
Poisson model :: A regression model for counts.
population :: The whole group a study wants to draw conclusions about.
post-hoc test :: A test run after ANOVA to find which groups differ, such as Tukey's test.
precision :: The share of cases predicted positive that are truly positive.
predicted probability :: A model's estimated probability of an outcome for a case.
prediction :: Using a model to estimate the outcome for new cases.
prediction interval :: A range within which a future observation is expected to fall with a stated probability.
predictive analysis :: Analysis aimed at predicting new cases rather than explaining or testing.
predictor :: A variable used to explain or predict the outcome.
preregistration :: Publicly recording hypotheses and planned analyses before seeing the data.
pretrained model :: A model already trained by others on large datasets, used as it is or adapted.
principal component :: A combination of variables that captures as much of their variation as possible.
principal component analysis :: A method that summarises many correlated variables with a few principal components.
project structure :: The systematic organisation of a research project's directories and files, such as `data/`, `scripts/`, and `output/`.
prompt :: The text given to a language model.
push :: In git, copying commits to an online repository such as GitHub.
Q-Q plot :: A plot comparing a variable's values with those expected from a normal distribution.
quadratic term :: A squared predictor in a regression model, which allows a curved relationship.
qualitative coding :: Assigning themes or categories to texts such as open-ended answers.
quartile :: The values that divide sorted data into four equal parts.
Quarto :: A publishing system that turns documents with text and code into reports, books, websites, and slides.
Python :: The open-source, general-purpose programming language and scientific computing environment used in this book.
Jupyter Notebook :: An interactive document format (`.ipynb`) combining executable Python code, explanatory markdown, and rich output.
R-squared | R² :: The share of the variation in the outcome that a model explains, from 0 to 1.
radial basis function :: A common kernel for support vector machines, which allows curved, rounded boundaries.
random effect :: In a mixed model, variation between groups (such as students) described by a distribution rather than a separate estimate for each group.
random forest :: An ensemble of decision trees, each grown on a bootstrap sample with random subsets of predictors.
random intercept :: A random effect that lets each group have its own average level.
random slope :: A random effect that lets each group have its own effect of a predictor, such as its own rate of change.
range :: The difference between the largest and smallest values.
rate ratio :: In a Poisson model, the multiplicative change in the expected count per unit of a predictor.
raw data :: Data as it was collected or exported, before any cleaning; never edited by hand.
reactive expression :: In Shiny, a calculation, made with `reactive()`, that is updated automatically when its inputs change.
reactivity :: Shiny's system for updating outputs automatically when inputs change.
recall | sensitivity :: The share of truly positive cases that a model predicts as positive.
pipeline :: In scikit-learn, a sequence of data preprocessing steps and estimators chained together into a single reproducible unit.
reference category :: The category of a categorical predictor that the others are compared with.
registered report :: A publication format in which a journal accepts a study's plan before the data is collected.
regression | Regression (prediction) :: Modelling or predicting a numeric outcome. In machine learning, regression means predicting a number rather than a category.
regular expression :: A pattern for matching text, such as `"\\b(money|fee)"`.
regularisation :: Penalising large coefficients to prevent overfitting, as in ridge and lasso regression.
reliability :: How consistently a scale measures what it measures.
ReLU :: Rectified linear unit: an activation function that sets negative values to zero.
remainder :: In a time series decomposition, what is left after removing trend and season.
render :: Running the code in a Quarto document and producing the finished output.
renv :: A package that records and restores the package versions used by a project.
repeated measures :: Several measurements of the same cases, such as each student in four semesters.
replicability :: Whether a new study, with new data, reaches the same conclusions.
reporting sentence :: A sentence in a results section that states a finding with its numbers, such as an estimate, interval, and p-value.
repository :: A project folder whose history git keeps; also its online copy on GitHub.
reproducibility :: Whether the same data and code give exactly the same results.
reproducible research :: Research whose results can be recomputed from the shared data and code.
research workflow :: The path of a research project from question and data to reported results.
residual | error :: The difference between an observed value and the value a model predicts.
reversed item :: A questionnaire item worded in the opposite direction to the others, which must be reversed before scoring.
ridge regression :: Regularised regression with a penalty on the squared coefficients, which shrinks them all towards zero.
RMSE :: Root mean squared error: the square root of the average squared prediction error.
ROC AUC :: The area under the ROC curve: how often a model ranks a positive case above a negative one; 0.5 is chance, 1 is perfect.
ROC curve :: A plot of sensitivity against the false positive rate across all classification thresholds.
rotation :: In factor analysis, turning the factors to make the loadings easier to interpret.
VS Code :: Visual Studio Code: a modern, extensible code editor with rich Python support, used throughout this book.
project workspace :: A project root directory opened in VS Code that defines the home of your research scripts and relative file paths.
sample :: The part of a population that is observed.
sample description ("Table 1") | sample description :: A table describing the participants, usually the first table of a results chapter.
sampling distribution :: The distribution of a statistic over many possible samples.
scale :: The mapping of continuous or discrete data values to physical coordinates, color maps, or visual sizes.
scale score :: A score combining several questionnaire items, usually their mean.
scaling :: Converting variables to a common scale, usually z-scores, before calculating distances.
scatter plot :: A plot of two numeric variables as points.
scree plot :: A plot of eigenvalues, used to choose the number of components or factors.
script :: A text file containing Python code (`.py`) that can be executed sequentially and rerun at any time.
seasonal naive method :: A benchmark forecast that repeats the value from the same season a cycle earlier.
seasonal period :: The length of a repeating pattern, such as 52 weeks or 12 months.
seasonal plot :: A plot that overlays the cycles of a time series to show its seasonal pattern.
seasonality :: A pattern in a time series that repeats at a fixed period.
seasonally adjusted series :: A time series with the seasonal component removed.
server :: In Shiny, the function that computes the outputs from the inputs.
setting :: Giving a plot parameter a fixed visual constant (such as `color="blue"`) rather than mapping it to a data column.
Streamlit :: A Python framework for rapidly creating interactive data applications and research dashboards in pure Python.
shrinkage :: Pulling coefficients towards zero, as regularisation does.
sigmoid :: The S-shaped function that turns any number into a value between 0 and 1.
significance level :: The threshold (usually 0.05) below which a p-value counts as statistically significant.
silhouette :: A measure of how much closer each case is to its own cluster than to the next nearest, from −1 to 1.
simulation :: Using random numbers to generate many possible outcomes, for example many possible futures of a time series.
singular fit :: A warning that a mixed model estimates some variation as zero, often because the model is too complex for the data.
skewness :: Asymmetry of a distribution; a long tail to the right is positive skew.
slope :: The change in the predicted outcome for a one-unit change in a predictor.
small cells :: Combinations of variables that describe very few people, who could be identified.
SMOTE :: A method that balances classes by creating artificial cases of the rare class between existing ones.
specificity :: The share of truly negative cases that a model predicts as negative.
stability :: Whether clusters or results stay the same under small changes to the data or the method.
standard deviation :: A measure of spread: roughly the typical distance of values from the mean.
standard error :: The standard deviation of a sampling distribution; the uncertainty of an estimate.
statistic :: A number calculated from a sample, such as a mean or a t value.
statistically significant :: A result with a p-value below the significance level.
STL :: Seasonal and trend decomposition using loess: a flexible method for decomposing a time series.
stratified split :: A split of the data that keeps the same share of each outcome class in each part.
structured output :: A language model's answer in a fixed format, such as one category from a list, that code can use directly.
supervised learning :: Machine learning with a known outcome to predict.
support vector :: A case close to the boundary of a support vector machine, which determines where the boundary lies.
support vector machine :: A classifier that separates classes with the widest possible margin.
symmetrical :: Having the same shape on both sides of the centre.
synthetic data :: Artificial data with the structure of real data, used when the real data cannot be shared.
system prompt :: Instructions given to a language model before the conversation, such as a task and a codebook.
temperature :: A setting of a language model that controls how random its answers are; 0 gives the most likely answer.
test set :: Data set aside to evaluate a final model once, at the end.
theme :: In ggplot2, the non-data appearance of a plot, such as fonts and background. In qualitative coding, a category of meaning.
threshold :: The probability above which a classifier predicts the positive class.
Series :: A one-dimensional labeled pandas array representing a single column of data in a DataFrame.
tidy data :: Data with one variable per column, one observation per row, and one value per cell.
scientific Python ecosystem :: The cohesive suite of foundational libraries (pandas, NumPy, SciPy, Matplotlib, Seaborn, Scikit-Learn, Statsmodels) that power modern data science.
time plot :: A plot of a time series against time.
time series :: Observations of one quantity at regular intervals over time.
token :: A word or part of a word, the unit of text a language model reads and writes.
training :: Adjusting a model's weights or parameters to fit the training data.
training cut-off :: The date after which a language model's training data contains no information.
training set :: The data used to build and tune a model.
transformer :: The neural network architecture behind large language models.
tree depth :: The number of questions in a row a decision tree may ask.
trend :: The long-term direction of a time series.
trend line :: A line added to a scatter plot to show the overall relationship.
true negative :: A negative case correctly predicted negative.
true positive :: A positive case correctly predicted positive.
tsibble :: A data frame for time series, which knows which column is time.
Tukey's test :: A post-hoc test comparing every pair of groups, with a correction for multiple comparisons.
tuning :: Choosing hyperparameters by comparing their performance, usually with cross-validation.
two-sample t-test :: A test comparing the means of two independent groups.
two-tailed test :: A test that looks for a difference in either direction.
two-way ANOVA :: ANOVA with two factors, including their interaction.
type conversion :: Changing a value from one data type to another, such as text to numbers.
Type I error :: Rejecting a true null hypothesis: a false alarm.
Type II error :: Failing to reject a false null hypothesis: a missed effect.
uncertainty :: In a mixture model, 1 minus a case's largest membership probability.
underfitting :: A model too simple to capture the real pattern in the data.
unimodal :: Having one peak.
unsupervised learning :: Machine learning without an outcome, looking for structure such as clusters.
upsampling :: Balancing classes by repeating cases of the rare class in the training data.
user interface :: In Shiny, what the user sees: inputs and places for outputs.
value label :: A label attached to a coded value, such as 1 = "Strongly disagree", as in SPSS files.
variable label :: A longer description attached to a variable, as in SPSS files.
variable selection :: Choosing which predictors to keep in a model; the lasso does it automatically.
variance :: The average squared distance from the mean; the square of the standard deviation.
array | vector :: A one-dimensional homogeneous sequence of numbers in NumPy (`np.array`) or pandas Series.
vector format :: An image format, such as PDF or SVG, that stays sharp at any size.
DataFrame method :: A pandas method that performs an operation on a DataFrame, such as `.query()`, `.assign()`, or `.groupby()`.
version control :: Keeping a history of every change to a project's files.
Ward's method :: A way of merging clusters in hierarchical clustering that keeps them as compact as possible.
weak learner :: A simple model, such as a small tree, that is only slightly better than chance on its own; boosting combines many.
weight :: In a neural network, the number by which an input is multiplied; learned during training.
weight decay :: A penalty on large weights in a neural network, which prevents overfitting.
Welch t-test :: A two-sample t-test that does not assume equal population variances, calculated in Python with `scipy.stats.ttest_ind(..., equal_var=False)`.
wide format :: Data with repeated measurements side by side in columns, one row per case.
Wilcoxon signed-rank test :: A non-parametric test comparing two measurements on the same cases.
within-group variation :: How much values vary around their own group mean; the denominator of the ANOVA F statistic.
Pipeline :: In scikit-learn, a composite estimator combining transformers and a predictor model.
model comparison grid :: Systematically evaluating multiple candidate models and preprocessing pipelines across cross-validation folds.
working directory :: The filesystem directory from which Python scripts resolve relative file paths by default.
XGBoost :: Extreme gradient boosting: a fast, widely used boosting method.
YAML header :: The settings at the top of a Quarto document, between two `---` lines.
z-score :: A value expressed as the number of standard deviations from the mean.
research question :: A focused question that says precisely what a study will find out, narrow enough that data can answer it.
descriptive question :: A research question about what is: how much, how many, how often.
relational question :: A research question about which variables go together. It establishes association, not cause.
causal question :: A research question about what leads to what. It needs a design that rules out other explanations, ideally an experiment.
hypothesis :: A prediction, stated before the data is analysed, of what the data will show; precise enough to be wrong.
falsifiability :: The property of a claim that some possible result would contradict it. A hypothesis that fits every possible result tells us nothing.
directional hypothesis :: A hypothesis that predicts the direction of an effect, such as "higher" or "lower".
non-directional hypothesis :: A hypothesis that predicts a difference or relationship without saying in which direction.
unit of analysis :: What one row of the data represents, and what the question is about: a student, a semester, a supervisor.
construct :: An idea that cannot be observed directly, such as stress or wellbeing, and must be measured indirectly.
operationalisation :: The decision about how a construct is measured: which questions, records, or instruments turn it into a variable.
self-report :: A measure based on what participants say about themselves, such as their estimated hours of sleep.
level of measurement :: What the values of a variable mean (nominal, ordinal, interval, or ratio), which decides the summaries and tests that make sense.
nominal :: A level of measurement for categories with no order, such as faculty.
ordinal :: A level of measurement for ordered categories whose distances are unknown, such as none, part-time, and full-time employment.
interval :: A level of measurement with equal distances between values but no true zero, such as a wellbeing index.
ratio :: A level of measurement with equal distances and a true zero, so that "twice as much" is meaningful, such as hours of sleep.
ordered factor :: A factor whose levels have an order, created with `factor(..., ordered = TRUE)`.
moderator :: A variable that changes the strength or direction of the relationship between a predictor and an outcome.
mediator :: A variable on the path between a predictor and an outcome, through which the predictor has its effect.
validity :: Whether a measure measures what it claims to, or whether a study's conclusions are justified.
internal consistency :: The extent to which the items of a scale agree with each other, often measured with Cronbach's alpha.
test-retest reliability :: The extent to which a measure gives similar results for the same people on two occasions.
inter-rater reliability :: The extent to which two people coding or rating the same material agree, often measured with Cohen's kappa.
content validity :: Whether the items of a measure cover the whole construct.
construct validity :: Whether a score behaves as the construct should: related to similar measures, less related to different ones.
internal validity :: Whether a study can rule out other explanations for its results. Highest in randomised experiments.
external validity :: Whether a study's results apply beyond it, to other people, places, and times.
study design :: The plan for who is measured, on what, when, and under which conditions.
randomised experiment :: A study in which the researcher assigns the treatment by chance, so that the groups differ only by chance at the start.
quasi-experiment :: A study that compares groups receiving different treatments that were not assigned by chance.
self-selection :: When people choose their own group, such as volunteering for a workshop, so that the groups may differ from the start.
cross-sectional design :: A design that measures every variable once, at one time.
longitudinal design :: A design that measures the same people repeatedly over time.
sampling frame :: A list of the members of a population, from which a sample can be drawn.
simple random sampling :: Sampling in which every member of the population has the same chance of being chosen.
stratified sampling :: Sampling in which the population is divided into groups (strata) and a random sample is drawn from each.
cluster sampling :: Sampling whole groups, such as all the students of randomly chosen supervisors.
convenience sampling :: Sampling whoever is easy to reach. Common, and the weakest basis for generalising.
random error :: The difference between an estimate and the truth caused by which cases happened to be selected. It shrinks as the sample grows.
power :: The probability that a study detects an effect of a given size, if the effect is real. A common target is 80%.
permutation test :: A test that builds the null distribution by shuffling group labels many times, and compares the observed result with the shuffled ones.
null distribution :: The distribution of a statistic that would be expected if the null hypothesis were true, used to judge how surprising the observed result is.
multiple testing :: Running many tests in one study. Each test carries its own risk of a false alarm, so the chance of at least one grows with the number of tests.
case :: One unit that is measured in a study, such as a student, a patient, or a school; one row of a data table.
variable :: One characteristic measured on every case, such as age or faculty; one column of a data table.
data matrix :: The arrangement of data as a table with one row per case and one column per variable.
data cleaning :: Preparing raw data for analysis: removing test and duplicate cases, making categories consistent, marking missing values, and correcting or removing impossible values, with every decision recorded.
exploratory graph :: A quick graph made by the researcher to understand the data: to check distributions, find unusual values, and notice patterns.
explanatory graph :: A carefully designed graph made for readers, to show a finding clearly and accurately.
graphical perception :: How people read values from graphs. Positions and lengths are judged most accurately, then angles, areas, and colours.
aspect ratio :: The ratio of a graph's width to its height. It changes how steep lines and slopes appear.
qualitative palette :: A set of clearly different colours of similar strength, used to distinguish categories.
sequential palette :: Colours running from light to dark, used for quantities that go in one direction.
diverging palette :: Colours running in two directions away from a meaningful midpoint, such as zero, used for values that can be positive or negative.
deviation :: The distance of a value from the mean, $x_i - \bar{x}$. The standard deviation summarises the deviations of all values.
latent variable :: A variable that cannot be observed directly, such as stress, and is assumed to cause part of the answers to the items that measure it.
design effect :: How many times more grouped observations are needed to give the same information as independent ones: 1 + (m - 1) × ICC, where m is the group size.
generalisation :: The ability of a model to perform well on new data, not only on the data it learned from.
bias-variance trade-off :: The balance between a model too simple to capture the pattern (high bias) and one so flexible that it follows the noise of each sample (high variance). Error on new data is lowest in between.
misclassification cost :: The cost assigned to each kind of error of a classifier, such as missing a case or raising a false alarm. The costs determine the best threshold.
log loss :: The measure of error used to fit logistic regression and classification networks: small when high probabilities are given to the cases that did occur and low probabilities to those that did not.
garden of forking paths :: The many reasonable choices in an analysis. Choosing among them after seeing the results inflates the chance of a false positive.
chain of reasoning :: The sequence of steps behind a research conclusion: question, hypothesis, design, variables, analysis, result, conclusion, and limitation.
reporting standard :: A published list of the information a research report must contain, such as JARS for psychology, CONSORT for randomised trials, and STROBE for observational studies.
