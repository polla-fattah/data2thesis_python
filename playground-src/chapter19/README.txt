FROM DATA TO THESIS: Using Python for Non-Technical
Playground, Chapter 19: Putting It All Together

The complete thesis project, from the raw survey export to a results chapter.

How to run it
1. Open this folder in VS Code, PyCharm, or your chosen terminal/editor.
2. Run python scripts/01_clean_data.py. It reads data-raw/wellbeing_raw.xlsx
   and writes clean tables to data/.
3. Run python scripts/02_analysis.py. It fits the models and writes
   output/results.pkl and output/figure-1.png.
4. Render results.qmd (quarto render results.qmd). It produces the results
   chapter as a web page and a Word document, with every number taken dynamically
   from the analysis.
Then work through exercises.txt, the project tasks. exercises.py holds the Python
parts of the playground page, in four parts (practise, go further, check your
understanding, do it yourself), with answers in solutions.py; it runs the
cleaning script first if data/ does not exist yet.

The project needs these packages (install once):
pip install pandas numpy scipy statsmodels matplotlib seaborn openpyxl tabulate

Folders
- data-raw/   the survey export; never edit it by hand
- scripts/    the scripts, numbered in the order they run
- data/       clean data, created by scripts/01_clean_data.py
- output/     results and figures, created by scripts/02_analysis.py
Everything in data/ and output/ can be deleted and recreated by running the scripts.

Please note: Elaf and her data are fictional. The data was generated by a
computer program to look realistic, and its patterns were built in by the
author. It describes no real people and is not evidence about real students;
do not cite or use it as research findings.
