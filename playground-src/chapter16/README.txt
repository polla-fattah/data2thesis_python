FROM DATA TO THESIS: Using Python for Non-Technical
Playground, Chapter 16: Time Series Forecasting

How to use this project
1. Open this folder in VS Code, PyCharm, or your favourite Python editor.
2. Open exercises.py. It has four parts:
   A. Practise the chapter       the book's exercises with pandas and statsmodels, blanks (______) to fill
   B. Go further                 new exercises beyond the book
   C. Check your understanding   short questions to answer in your own words
   D. Do it yourself             open tasks: no starter code and no answers
   Run lines interactively or run the whole script with:
   python exercises.py
3. Check parts A to C in solutions.py, after you have tried each one yourself.
   Part D has no solutions: the tasks are open, as in your own thesis.

The exercises need these packages (install once):
pip install pandas numpy statsmodels scikit-learn matplotlib

Files
- exercises.py            the four parts, with starter code for parts A and B
- solutions.py            solutions for parts A and B, model answers for part C
- counselling_visits.csv  5 years of weekly visit counts (260 weeks)
- flights.csv             monthly airline passenger totals (1949–1960)
- co2.csv                 monthly atmospheric CO2 concentrations at Mauna Loa (1959–1997)
